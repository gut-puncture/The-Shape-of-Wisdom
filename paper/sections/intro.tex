\section{Introduction}
\label{sec:intro}

Ask a language model ``What country is An\'{i}bal Ponce a citizen of?'' and, a few dozen layers later, it answers ``Argentina''. On the way, the model's internal state at the answering position changes at every layer. This paper asks what shape that change has. Does the state wander, drift slowly toward the answer, or arrive somewhere definite? And if it arrives somewhere, is that the same place for every question with the same answer?

We find that it is. As a question passes through the network, its state moves into a region that it shares with every other question to which the model gives the same answer. We call this region the answer's \emph{place}. Figure~\ref{fig:hero} shows this in Llama-3.1-8B. Early in the network, questions whose answers are twelve different countries form one tangled cloud. Within a few layers, most of them separate into one strand per country.

We study places from four sides. First, we ask when the answer becomes readable from the state. In each of four models, readability jumps within a single layer, at a depth that differs between models (Section~\ref{sec:step}). Second, we ask whether a place depends on how the question is asked. It does not. The place of a country learned from questions about people also identifies that country in questions about towns and films, and it survives rewording (Section~\ref{sec:shared}). Third, we ask whether the model uses places. Moving a state into a place after the jump makes the model give that place's answer. Random moves of the same size rarely do, and moves made before the jump have no effect (Section~\ref{sec:steer}).

Fourth, we look at wrong answers. A place is defined by the answer the model gives, not by the true answer, so a wrong answer also lands in a place. Some wrong answers are near misses: shown the options, the model picks the right one. Others are real gaps in knowledge. The model's confidence barely tells the two apart, but where the state sits does. In a near miss, the right answer's place is close behind the place the state reached (Section~\ref{sec:errors}).

In these models and on these questions, the answer does not sharpen steadily layer by layer. It appears at one depth, in a region shared with every other question that gets the same answer. A confident mistake reaches the region of the answer it gives in the same way.
