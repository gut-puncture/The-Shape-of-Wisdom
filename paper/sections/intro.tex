\section{Introduction}
\label{sec:intro}

Ask a language model ``What country is An\'{i}bal Ponce a citizen of?'' and, a few dozen layers later, it answers ``Argentina''. Between the question and the answer the model's internal state at the answering position changes at every layer. This paper asks what shape that change has. Does the state wander, drift slowly toward the answer, or arrive somewhere definite? And if it arrives somewhere, is that somewhere the same for every question with the same answer?

We find that it is. As a question passes through the network, the state moves into a region shared by all questions to which the model gives the same answer. We call this region the answer's \emph{place}. Figure~\ref{fig:hero} shows it directly: early in Llama-3.1-8B, questions whose answers are twelve different countries form one tangled cloud; within a few layers they separate into one strand per country.

Four properties make places more than a picture. First, the answer becomes readable suddenly. In each of four models it jumps within a single layer at a model-specific depth, most sharply when the answer is a name (Section~\ref{sec:step}). Second, places are shared across questions: the same place is reached from different relations and wordings, and reading it does not need the output directions of the answer's own name (Section~\ref{sec:shared}). Third, places are causal. Moving a state into a place after the jump makes the model give that place's answer, while random moves of the same length rarely do and moves before the jump are ignored (Section~\ref{sec:steer}). Fourth, places follow the answer the model gives rather than the true answer, and this makes wrong answers legible: where a wrong answer sits predicts whether the model still recognises the right one, better than the model's confidence does (Section~\ref{sec:errors}).

In these models and on these questions, then, the answer does not sharpen steadily layer by layer. It becomes readable at one depth, in a region shared with every other question that receives the same answer, and a confident mistake reaches the region of the answer it gives in the same way. The truth only decides which region it should have been.
