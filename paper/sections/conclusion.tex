\section{Conclusion}
\label{sec:conclusion}

We followed the state from which four language models answer short factual questions, layer by layer. In all four, the answer becomes readable from the state within a single layer, at a depth that differs between models. From that layer on, questions with the same answer gather around a shared centroid. The centroid follows the answer the model gives. It does not depend on the type of fact or the wording, and it is not simply the output direction of the answer word. When the model is wrong, it follows the wrong answer. The model uses it: moving a state to an answer's centroid after the onset makes the model give that answer, and the same move before the onset does nothing, even when made larger. The onset is when the answer becomes both readable and steerable. Because wrong answers have centroids too, the state shows which mistakes are near misses, better than the model's confidence does. Whether the same picture holds for open-ended answers, for reasoning over several steps and for larger models is the natural next question.
