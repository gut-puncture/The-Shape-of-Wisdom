\section{Conclusion}
\label{sec:conclusion}

We followed the state from which four language models answer short factual questions, layer by layer. In all four, the answer becomes readable from the state within a single layer. The depth of this onset differs between models. From the onset on, questions with the same answer gather in a shared place. The place does not depend on the relation or the wording of the question, and it can be read without the directions that write the answer's name. Moving a state into a place after the onset makes the model give that place's answer; before the onset, the same move does nothing. Places follow the answer the model gives rather than the true one, so wrong answers land in places too. Where they land separates near misses, which the model recognises when shown the options, from real gaps in knowledge, and it does so better than the model's confidence. Whether the same picture holds for open-ended answers, for reasoning over several steps and for larger models is the natural next question.
